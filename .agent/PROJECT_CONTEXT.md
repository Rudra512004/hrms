# HRMS Project Context

This is the central Human Resources Management System (HRMS) project.
The project is a full-stack application with a Django/Python backend and a React/Vite frontend.

## Goals
- Provide comprehensive HR functionalities including employee management, attendance, leave, payroll, and more.
- Implement robust, dynamic Role-Based Access Control (RBAC).

## Stack
- Backend: Django, Django REST Framework
- Frontend: React, Vite
- Database: PostgreSQL (or chosen DB via Django ORM)
