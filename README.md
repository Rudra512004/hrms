# HRMS Project

This is the comprehensive Human Resources Management System project. It provides robust HR functionality paired with dynamic Role-Based Access Control (RBAC).

## Structure
- `backend/`: Django/Python REST API
- `frontend/`: React/Vite single-page application
- `docs/`: Project documentation
- `.agent/`: Project rules and guidelines

Please see `.agent/DEV_WORKFLOW.md` for instructions on how to run the project.
